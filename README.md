# 📝 AI 메모장

캘린더, 할 일, 메모를 한곳에 모으고, 앱을 열면 "오늘 먼저 할 일 TOP 3"가 맨 위에 보이는 메모장입니다. (1단계: AI 없는 기본 기능)

## 기능
- 메모: 쓰기 / 수정 / 삭제 / 검색
- 할 일: 마감일, 중요도(높음·보통·낮음), 완료 체크, 오늘·전체·완료 필터
- 캘린더: 월간 달력, 날짜별 일정·할 일, 마감일 자동 표시
- 첫 화면: 우선순위(마감일 → 중요도 → 입력 순)로 계산한 TOP 3와 오늘 일정

## 실행 방법 (Windows)
1. `시작.bat`을 더블클릭합니다.
2. 브라우저에 `http://localhost:5000`이 열립니다.
3. 끌 때는 검은 창을 닫습니다.

서버 없이 `index.html`을 더블클릭해서 열어도 됩니다.

## 참고
- 데이터는 사용 중인 브라우저에만 저장되며 다른 기기와 공유되지 않습니다.
- 주민등록번호, 계좌번호, 비밀번호 같은 민감한 정보는 메모에 적지 마세요.
